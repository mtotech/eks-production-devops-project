# Automated Testing

## Overview

This project uses Pytest for automated testing.

The testing framework validates:

- API Availability
- Response Status Codes
- Application Logic
- CI/CD Quality Gates

---

## Run Tests

pytest

---

## Run Verbose Tests

pytest -v

---

## CI Integration

Tests are automatically executed through GitHub Actions before deployment.

---

## Benefits

- Early Bug Detection
- Automated Validation
- Deployment Confidence

## Learning Outcomes

- Test Automation
- Pytest
- CI/CD Integration
